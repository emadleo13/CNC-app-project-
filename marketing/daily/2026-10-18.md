Heidenhain alarm 130 — PLANE FUNCTION NOT DEFINED

A tilted working plane was referenced, but no working plane has been activated.

Most common causes:
• PLANE RESET was not issued before a new PLANE command
• The PLANE function was removed or commented out
• The kinematics description is missing the tilting axes

First thing to try: Insert the correct PLANE function before the machining block

Takes about two minutes to track down once you know where to look.
