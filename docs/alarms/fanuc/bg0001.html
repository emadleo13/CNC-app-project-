Fanuc Alarm BG0001 — CANNOT EXECUTE IN BACKGROUND EDIT

info

An operation was requested that is not permitted while background editing is active (editing one program while another runs).

Likely causes of Fanuc alarm BG0001

  • Operator attempted to start a cycle, jog, or change modes while in background edit
  • Background-edited program is the same program currently selected for execution

How to clear alarm BG0001

  1. Exit background edit mode (return to the foreground program display) before performing the operation
  2. Make sure the program being background-edited is not the one currently running
  3. Save background edits, then return to the main program screen
