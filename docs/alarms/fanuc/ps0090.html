Fanuc Alarm PS0090 — REFERENCE RETURN INCOMPLETE

warning

The reference return (home position) has not been completed for one or more axes. Operations requiring known position cannot proceed.

Likely causes of Fanuc alarm PS0090

  • Machine powered on but not homed
  • Reference return sequence was interrupted by alarm
  • Axis lost home position due to encoder battery failure
  • Not all axes were included in the reference return

How to clear alarm PS0090

  1. Perform reference return (G28) for all axes in the correct sequence
  2. Clear any active alarms before attempting reference return
  3. Check encoder battery status — dead battery loses position
  4. Home axes in order specified by machine builder (typically Z first)
