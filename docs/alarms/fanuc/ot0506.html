Fanuc Alarm OT0506 — +OVERTRAVEL: HARDWARE LIMIT

critical

An axis physically reached its positive hardware limit switch. The limit switch has been triggered.

Likely causes of Fanuc alarm OT0506

  • Axis moved past the software limits due to parameter error
  • Software overtravel limits disabled or set incorrectly
  • Emergency motion moved axis past limits

How to clear alarm OT0506

  1. IMPORTANT: Do not power off machine — axis may be stuck against hard stop
  2. Jog axis slowly in negative direction using JOG mode
  3. Check why software limits did not prevent reaching hard limit
  4. Verify parameters 1320/1321 (software limits) are set correctly
