Fanuc Alarm PS0003 — TOO MANY DIGITS

warning

A word in the NC program contains more digits than allowed by the controller.

Likely causes of Fanuc alarm PS0003

  • Incorrect number format — e.g., G01 instead of G1 is fine, but very long numbers
  • Post-processor generating non-standard word lengths
  • Extra digits in an X, Y, Z coordinate word

How to clear alarm PS0003

  1. Check the program block shown in the alarm detail
  2. Reduce the number of decimal places or digits in the word
  3. Verify post-processor is set correctly for FANUC format
