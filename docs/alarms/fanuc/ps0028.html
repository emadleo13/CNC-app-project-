Fanuc Alarm PS0028 — ILLEGAL PLANE SELECTION

warning

A circular interpolation (G02/G03) or canned cycle was commanded with an axis address that does not belong to the currently selected plane (G17/G18/G19).

Likely causes of Fanuc alarm PS0028

  • G02/G03 block uses I/J/K or axis words not matching the active plane
  • Canned cycle (G81-G89) called while the wrong plane is active
  • Plane was changed earlier in the program and not reset before this block

How to clear alarm PS0028

  1. Check the active plane (G17=XY, G18=XZ, G19=YZ) at the alarm block
  2. Add the correct G17/G18/G19 command before the circular move or cycle
  3. Verify I/J/K (or the equivalent radius/axis words) match the selected plane
