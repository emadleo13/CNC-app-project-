Fanuc Alarm OT0507 — -OVERTRAVEL: HARDWARE LIMIT

critical

An axis physically reached its negative hardware limit switch.

Likely causes of Fanuc alarm OT0507

  • Software limits not set correctly
  • Axis moved past negative software limits
  • Homing error placing axis reference incorrectly

How to clear alarm OT0507

  1. Jog axis slowly in positive direction in JOG mode
  2. Investigate why software limits did not stop the axis
  3. Reset reference point if homing error caused the issue
  4. Verify negative software limits in parameter 1321
