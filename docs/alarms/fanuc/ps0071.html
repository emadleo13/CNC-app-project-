Fanuc Alarm PS0071 — DATA NOT FOUND

warning

A referenced program number or sequence number was not found in memory.

Likely causes of Fanuc alarm PS0071

  • M98 P_ references a program number that does not exist
  • GOTO N_ references a sequence number not in the program
  • Program was deleted or never loaded
  • Typo in program number or sequence number

How to clear alarm PS0071

  1. Verify the referenced program number exists in memory
  2. Check M98 P value matches an existing O-number program
  3. Load the missing subprogram to machine memory
  4. Verify sequence numbers (N words) exist in the program
