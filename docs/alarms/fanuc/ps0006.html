Fanuc Alarm PS0006 — IMPROPER G CODE

warning

An unrecognized or invalid G-code was found in the program block. The G-code number is not supported by this controller.

Likely causes of Fanuc alarm PS0006

  • G-code not available on this FANUC model or series
  • Typo in G-code number
  • G-code from different controller dialect used in FANUC program
  • Optional G-code function not activated

How to clear alarm PS0006

  1. Verify the G-code is valid for this FANUC controller series
  2. Check for typos in the G-code number
  3. Ensure optional features are enabled if the G-code requires them
  4. Use the correct post-processor for your FANUC model
