Fanuc Alarm PS0073 — ILLEGAL SEQUENCE NUMBER

warning

A sequence number (N word) error was detected. The N address value is invalid or out of the allowed range.

Likely causes of Fanuc alarm PS0073

  • N number exceeds maximum allowed value
  • Duplicate sequence numbers in program
  • N number is negative or contains decimal
  • Sequence number format incorrect

How to clear alarm PS0073

  1. Check N word values are within allowed range (typically 1-99999)
  2. Remove duplicate N numbers from program
  3. Ensure N values are positive integers only
  4. Verify post-processor N-number generation settings
