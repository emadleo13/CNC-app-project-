Fanuc Alarm PS5016 — END POINT NOT ON ARC

warning

The arc endpoint does not match the calculated arc based on the center point. The radius from center to start differs from center to end beyond tolerance.

Likely causes of Fanuc alarm PS5016

  • Incorrect I, J, K values for arc center
  • Start/end point calculation error in CAM
  • Rounding errors in coordinate values
  • R value does not produce valid arc to endpoint
  • Wrong plane selected for the arc

How to clear alarm PS5016

  1. Verify I/J/K values define an arc center equidistant from start and end points
  2. Use R format instead of I/J/K if center calculation is difficult
  3. Increase decimal precision in coordinate output from CAM
  4. Check that G17/G18/G19 plane selection matches arc axes
  5. Adjust parameter 3410 for arc radius tolerance if rounding is the issue
