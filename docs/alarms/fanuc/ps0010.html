Fanuc Alarm PS0010 — IMPROPER G-CODE

warning

A G-code in the program is not recognized by the controller.

Likely causes of Fanuc alarm PS0010

  • G-code not available on this FANUC model
  • Typo in G-code number
  • G-code from a different controller (Siemens, Haas) in a FANUC program
  • Optional G-code function not installed

How to clear alarm PS0010

  1. Check if the G-code number is valid for FANUC
  2. Verify optional functions are installed if needed
  3. Review program for G-codes from other controller dialects
  4. Check FANUC parameter settings for G-code option activation
