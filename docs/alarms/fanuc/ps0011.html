Fanuc Alarm PS0011 — DATA IS OUT OF RANGE

warning

A value entered in the program, parameter, or offset table exceeds the minimum or maximum range allowed for that item.

Likely causes of Fanuc alarm PS0011

  • Tool offset or work offset value entered with too many digits or wrong decimal placement
  • Feedrate, spindle speed, or dwell value exceeds the allowable range
  • Parameter value outside the documented range for that parameter number

How to clear alarm PS0011

  1. Check the value shown in the alarm detail and compare against the allowable range
  2. Re-enter the offset, parameter, or program word with a valid value
  3. Verify decimal point placement — a missing decimal can produce a value 1000x too large
