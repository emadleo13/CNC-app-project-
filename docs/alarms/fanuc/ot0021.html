Fanuc Alarm OT0021 — OVER TRAVEL Y

error

The Y axis has exceeded its software travel limit. The programmed position is outside the allowed Y axis range.

Likely causes of Fanuc alarm OT0021

  • Program Y coordinate exceeds machine travel
  • Incorrect work offset (G54) Y value
  • Incremental moves (G91) accumulating past Y limit
  • Tool radius compensation pushing path outside limit

How to clear alarm OT0021

  1. Jog Y axis back within travel limits
  2. Verify work offset Y value is correct
  3. Check all Y coordinates in program against machine travel
  4. Review soft limit parameters 1320/1321 for Y axis
