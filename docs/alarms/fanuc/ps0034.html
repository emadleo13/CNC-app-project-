Fanuc Alarm PS0034 — NO CIRCULAR ARC

warning

G02 or G03 circular interpolation was commanded but I, J, K arc center values or R radius value were not specified, or both were specified simultaneously.

Likely causes of Fanuc alarm PS0034

  • I/J/K values missing from G02/G03 block
  • R radius not specified
  • Both I/J/K and R specified in same block

How to clear alarm PS0034

  1. Add I, J, or K value to define arc center, or use R for radius
  2. Use either I/J/K or R — not both in same block
  3. Example: G02 X10. Y10. I5. J0. or G02 X10. Y10. R7.071
