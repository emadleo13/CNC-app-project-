Fanuc Alarm PS5013 — TOOL COMPENSATION CANCEL

warning

Tool radius compensation (G41/G42) was not cancelled before executing a G-code that requires it to be off. Compensation must be cancelled with G40 first.

Likely causes of Fanuc alarm PS5013

  • G40 not programmed before G28, G30, or G27
  • Cutter compensation active when changing planes
  • G40 missing before tool change (M06)
  • Program structure error with compensation still active

How to clear alarm PS5013

  1. Add G40 before G28, G30, G27, or any reference return commands
  2. Cancel compensation (G40) before plane changes (G17/G18/G19)
  3. Ensure G40 is programmed before tool change blocks
  4. Review program structure — G40 must precede certain operations
