Fanuc Alarm PS0001 — TH ALARM — Tape format error

warning

A parity error was detected in the input data. A character in the ISO code stream has an incorrect bit count (odd parity check failed).

Likely causes of Fanuc alarm PS0001

  • Corrupted DNC data transmission
  • Incorrect RS-232 serial settings (baud rate, parity, stop bits)
  • File transferred with wrong encoding (not ASCII)
  • Noise on communication cable

How to clear alarm PS0001

  1. Verify DNC settings: baud rate, data bits (7 or 8), parity, and stop bits match on both sides
  2. Check serial cable length and shielding
  3. Try retransferring the file
  4. Open the NC file in a text editor to check for non-ASCII characters
