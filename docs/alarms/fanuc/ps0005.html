Fanuc Alarm PS0005 — NO DATA AFTER ADDRESS

warning

An address letter (G, X, M, etc.) was found at the end of a block with no numeric data following it.

Likely causes of Fanuc alarm PS0005

  • Address letter without a number: e.g., just G or just X
  • Block formatting error in CAM post-processor
  • Manual editing error

How to clear alarm PS0005

  1. Check alarm block — find the address with missing value
  2. Add the required numeric value after the address letter
  3. Review post-processor output for standalone address letters
