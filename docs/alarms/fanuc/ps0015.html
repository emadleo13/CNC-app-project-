Fanuc Alarm PS0015 — TOO MANY AXES COMMANDED

warning

More axes were commanded simultaneously in a single block than the machine can interpolate at once.

Likely causes of Fanuc alarm PS0015

  • Block contains more simultaneous axis moves than controller allows
  • Program written for 5-axis machine running on 3-axis controller
  • Post-processor configured for more axes than available
  • Rotary and linear axes combined exceeding interpolation limit

How to clear alarm PS0015

  1. Split the motion into multiple blocks with fewer simultaneous axes
  2. Verify post-processor matches machine axis configuration
  3. Check FANUC parameter for maximum simultaneous interpolation axes
  4. Remove axes from the block that are not needed for this move
