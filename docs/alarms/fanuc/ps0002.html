Fanuc Alarm PS0002 — TV ALARM — Block parity error

warning

A parity error was detected in an NC block. The total number of characters in the block is incorrect (odd number when even expected, or vice versa).

Likely causes of Fanuc alarm PS0002

  • Data corruption during serial/DNC transfer
  • File encoding issue introducing extra characters
  • RS-232 noise causing character errors
  • Incomplete block received during transfer

How to clear alarm PS0002

  1. Retransfer the program file
  2. Verify RS-232 communication settings match between sender and receiver
  3. Check serial cable shielding and length (max recommended length)
  4. Open file in text editor and verify block structure
  5. Disable TV check if using newer protocol (parameter 0000 bit 0)
