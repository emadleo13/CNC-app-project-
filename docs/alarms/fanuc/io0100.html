Fanuc Alarm IO0100 — I/O LINK ALARM

critical

Communication with one or more I/O units on the FANUC I/O Link serial bus has failed.

Likely causes of Fanuc alarm IO0100

  • I/O unit power supply failure
  • I/O Link cable disconnected or damaged
  • I/O unit hardware failure
  • Terminator missing from I/O Link bus

How to clear alarm IO0100

  1. Check power supply to all I/O units
  2. Inspect I/O Link cables (flat ribbon cables between I/O units)
  3. Verify bus terminator is installed on the last I/O unit
  4. Power cycle and check which I/O unit is not responding
  5. Replace failed I/O unit
