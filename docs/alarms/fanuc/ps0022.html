Fanuc Alarm PS0022 — TOO MANY SUBPROGRAMS

warning

The maximum number of nested subprogram calls (typically 4 levels) has been exceeded.

Likely causes of Fanuc alarm PS0022

  • Too many M98 calls nested within each other
  • Program structure with deep call chains
  • Recursive M98 call (program calls itself)

How to clear alarm PS0022

  1. Flatten the program structure to reduce nesting levels
  2. FANUC 0i allows 4 levels of nesting; 30i allows more
  3. Check for unintentional recursive calls
  4. Reorganize program to call subprograms sequentially rather than nested
