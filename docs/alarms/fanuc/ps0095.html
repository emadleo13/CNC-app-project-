Fanuc Alarm PS0095 — PROGRAM NUMBER ALREADY IN USE

warning

An attempt was made to register a new program with an O-number that already exists in memory.

Likely causes of Fanuc alarm PS0095

  • A program with the same O-number was already loaded
  • Post-processor reused a program number from a previous job
  • Operator typed an existing program number when creating a new program

How to clear alarm PS0095

  1. Choose a different, unused program number
  2. Or delete/rename the existing program with that number first (back it up before deleting)
  3. Check the program directory (LIST PROGRAM) for the conflicting number
