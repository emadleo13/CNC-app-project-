Fanuc Alarm PS5009 — ILLEGAL OFFSET NUMBER

warning

A program block specifies a tool offset number (H or D) that is greater than the number of offsets supported by the control, or is negative.

Likely causes of Fanuc alarm PS5009

  • H or D number in the program exceeds the configured offset memory size
  • Typo produced an offset number such as H0 used where it is not permitted, or a 3-digit number on a control limited to 2-digit offsets
  • Offset memory size parameter set lower than the program expects

How to clear alarm PS5009

  1. Check the H/D number in the alarm block against the offset table size (Setting/Parameter for number of offsets)
  2. Correct the offset number in the program to a valid, existing entry
  3. Increase the offset memory parameter if the machine supports more offsets and the program legitimately needs them
