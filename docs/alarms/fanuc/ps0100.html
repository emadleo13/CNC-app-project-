Fanuc Alarm PS0100 — PARAMETER WRITE ENABLE

warning

The parameter write enable switch is in the ON position. This is a notification that parameters can be modified, which is normally restricted for safety.

Likely causes of Fanuc alarm PS0100

  • Parameter write enable key switch is ON
  • Parameter protect bit was intentionally cleared
  • Maintenance mode activated

How to clear alarm PS0100

  1. Turn parameter write enable switch to OFF after making changes
  2. This alarm is informational — it reminds you that parameters are unprotected
  3. Verify no unauthorized parameter changes were made
  4. Set parameter protect bit after completing maintenance
