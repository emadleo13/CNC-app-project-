Fanuc Alarm PS1098 — PROGRAM END (M02/M30) NOT FOUND

warning

The control reached the end of program memory or the end-of-tape character without encountering an M02 or M30 program-end command.

Likely causes of Fanuc alarm PS1098

  • Program was truncated during transfer (DNC/USB)
  • M02/M30 was deleted accidentally during editing
  • Program references a subprogram (M98) that never returns (M99) and falls through to end of memory

How to clear alarm PS1098

  1. Open the program and add M30 (or M02) at the end
  2. If the program was transferred, verify the file is complete and retransfer if needed
  3. Check that every M98 subprogram call has a matching M99 return
