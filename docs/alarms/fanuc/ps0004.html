Fanuc Alarm PS0004 — ADDRESS NOT FOUND

warning

A block was found that contains data (numbers) but no address letter (G, X, Y, etc.).

Likely causes of Fanuc alarm PS0004

  • Missing address letter before a number
  • Block starts with a number instead of an address
  • Post-processor error generating malformed blocks

How to clear alarm PS0004

  1. Check the alarm block for the missing address letter
  2. Verify all numbers have an address preceding them
  3. Review post-processor output for blocks with leading numbers without address letters
