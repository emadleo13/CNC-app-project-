Fanuc Alarm PS0101 — PLEASE TURN OFF POWER

warning

Parameters have been changed that require a power cycle to take effect. The machine must be turned off and back on.

Likely causes of Fanuc alarm PS0101

  • Machine parameters were modified that affect system initialization
  • Axis configuration parameters changed
  • Communication parameters modified
  • System-level parameters altered

How to clear alarm PS0101

  1. Turn off machine power completely (main breaker)
  2. Wait at least 10 seconds before turning power back on
  3. After restart, verify the parameter changes took effect
  4. Document which parameters were changed for reference
