Fanuc Alarm PS0085 — COMMUNICATION ERROR

error

A serial port or DNC communication error has occurred. Data transfer between the CNC and external device was interrupted.

Likely causes of Fanuc alarm PS0085

  • RS-232 cable disconnected or damaged
  • Baud rate mismatch between CNC and sending device
  • Buffer overflow during DNC transfer
  • Electrical noise on serial cable
  • DNC software stopped sending data

How to clear alarm PS0085

  1. Check RS-232 cable connections at both ends
  2. Verify communication parameters match (baud rate, data bits, parity, stop bits)
  3. Ensure DNC software is running and configured correctly on the PC
  4. Check cable shielding and routing away from power cables
  5. Reduce baud rate if buffer overflow errors occur
