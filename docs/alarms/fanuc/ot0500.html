Fanuc Alarm OT0500 — +OVERTRAVEL: SOFT 1

error

An axis exceeded the positive software travel limit (1st limit switch setting). The axis cannot move further in the positive direction.

Likely causes of Fanuc alarm OT0500

  • Program coordinates outside machine travel
  • Work offset placing tool near travel limit
  • Rapid traverse moved axis too far

How to clear alarm OT0500

  1. Jog axis in negative direction to clear the limit
  2. Verify work zero offset is within machine travel
  3. Check program coordinates — all axes must stay within soft limits
  4. Review soft limit parameters 1320 and 1321
