Fanuc Alarm OT0003 — STORED STROKE LIMIT 2 EXCEEDED

warning

The programmable (software) stroke limit area 2, set by parameters and enabled with G22, was violated by a commanded move.

Likely causes of Fanuc alarm OT0003

  • G22 stroke check is active and the program path enters the restricted area
  • Stroke limit 2 boundary parameters set incorrectly for the current fixture/tooling setup
  • Work offset places the part such that normal moves intersect the restricted zone

How to clear alarm OT0003

  1. Use G23 to disable stroke check 2 only if it is safe to do so for this setup
  2. Review stroke limit 2 boundary parameters against the actual fixture/tooling envelope
  3. Adjust the program path or work offset so it does not enter the restricted area
