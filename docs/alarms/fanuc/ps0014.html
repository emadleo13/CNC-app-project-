Fanuc Alarm PS0014 — COMMANDED FEED ZERO

warning

A feed rate of zero was programmed or is active during a cutting move (G01, G02, G03). The axis cannot move without a valid feed rate.

Likely causes of Fanuc alarm PS0014

  • F0 or no F word in the first cutting block
  • Modal feed rate was cleared and not reprogrammed
  • Feed per revolution mode active with spindle stopped (F = S x f = 0)
  • Feed override dial at 0%

How to clear alarm PS0014

  1. Add a valid F word to the cutting motion block
  2. Verify feed rate is non-zero: e.g., G01 X100. F200
  3. Check feed override dial is not at 0%
  4. If using G95 (feed per rev), ensure spindle is running
