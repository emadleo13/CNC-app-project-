Fanuc Alarm DS0301 — APC ALARM: ZERO POINT RETURN REQUIRED

error

The absolute encoder has lost its reference position, likely due to a dead backup battery. A reference point return (homing) is required.

Likely causes of Fanuc alarm DS0301

  • Battery was dead when machine was powered off
  • Battery was replaced while machine was powered off without capacitor holding position
  • Encoder replaced without re-establishing zero point

How to clear alarm DS0301

  1. Perform reference point return (zero return) for the affected axis
  2. Follow the machine builder's procedure for re-establishing absolute position
  3. Verify axis position after homing matches known reference marks
  4. Record new absolute position data
