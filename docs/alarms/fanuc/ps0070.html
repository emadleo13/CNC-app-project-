Fanuc Alarm PS0070 — MEMORY OVERFLOW

warning

The part program exceeds the available program memory. There is not enough storage to hold the program.

Likely causes of Fanuc alarm PS0070

  • Program file too large for available memory
  • Too many programs already stored in memory
  • Memory fragmentation leaving insufficient contiguous space
  • Large program with many blocks

How to clear alarm PS0070

  1. Delete unused programs to free memory space
  2. Use DNC mode to run large programs directly without loading to memory
  3. Break large programs into smaller subprograms
  4. Check available memory with program directory display
