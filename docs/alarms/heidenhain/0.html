Heidenhain Alarm 0 — EMERGENCY STOP activated

critical

The hardware Emergency Stop circuit has been triggered. All axis motion and spindle operation are immediately halted.

Likely causes of Heidenhain alarm 0

  • E-STOP button pressed on operator panel or pendant
  • Safety door opened during cycle
  • External E-STOP input signal activated
  • Machine hardware safety circuit opened

How to clear alarm 0

  1. Identify and resolve the cause before resetting
  2. Release E-STOP button by twisting clockwise
  3. Close all safety doors
  4. Press CE key to acknowledge after releasing E-STOP
  5. Restart NC and press NC START
