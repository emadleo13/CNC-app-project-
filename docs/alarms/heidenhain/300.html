Heidenhain Alarm 300 — FEED RATE MISSING

warning

A feed rate has not been programmed for a linear or circular move. The control cannot execute the motion without a defined feed rate.

Likely causes of Heidenhain alarm 300

  • F word not programmed before the first cutting move
  • Previous F value cancelled and not reprogrammed
  • FMAX not specified for rapid positioning block
  • Modal feed rate lost after program restart

How to clear alarm 300

  1. Add F value to the motion block: L X+100 Y+50 F500
  2. For rapid moves, use FMAX designation
  3. Ensure feed rate is defined before the first cutting move
  4. Check if feed rate was programmed in a skipped block
