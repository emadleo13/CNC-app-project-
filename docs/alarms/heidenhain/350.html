Heidenhain Alarm 350 — DIVISION BY ZERO

warning

A mathematical calculation in the NC program resulted in division by zero. The computation cannot be completed.

Likely causes of Heidenhain alarm 350

  • Q parameter used as divisor has value zero
  • Calculation cycle with zero denominator
  • Formula error in parametric programming
  • Uninitialized Q parameter defaulting to zero

How to clear alarm 350

  1. Check Q parameter values used in division operations
  2. Add a condition check before division: IF Q_ NE 0 GOTO
  3. Initialize all Q parameters to safe values at program start
  4. Review calculation formulas for potential zero-divisor cases
