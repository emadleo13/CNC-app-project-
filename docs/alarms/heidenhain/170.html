Heidenhain Alarm 170 — ROTARY AXIS TRAVEL LIMIT EXCEEDED

error

A programmed move on a rotary axis (A/B/C) exceeds its software travel limit.

Likely causes of Heidenhain alarm 170

  • The rotary axis was programmed beyond the limit set in the machine parameters
  • M94 (modulo rotation) was not used for a continuous rotary move
  • An incorrect tilting angle was used in the PLANE function
  • A datum shift on the rotary axis was miscalculated

How to clear alarm 170

  1. Use M94 to reduce the rotary axis position to within 0-360 degrees
  2. Check the software limit switch settings for the rotary axis
  3. Verify the PLANE angles are within the mechanical range
  4. Recalculate the datum shift for the rotary axis
