Heidenhain Alarm 130 — PLANE FUNCTION NOT DEFINED

error

A tilted working plane was referenced, but no working plane has been activated.

Likely causes of Heidenhain alarm 130

  • PLANE RESET was not issued before a new PLANE command
  • The PLANE function was removed or commented out
  • The kinematics description is missing the tilting axes
  • M128/TCPM was called without an active working plane

How to clear alarm 130

  1. Insert the correct PLANE function before the machining block
  2. Verify the kinematics table includes the tilting (rotary) axes
  3. Issue PLANE RESET at the start and end of the program
  4. Check that the tilting axes have been referenced
