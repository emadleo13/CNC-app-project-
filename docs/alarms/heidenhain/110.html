Heidenhain Alarm 110 — TOOL OVERSIZE

warning

The tool radius is larger than the programmed contour allows. The tool cannot fit in the programmed geometry without gouging.

Likely causes of Heidenhain alarm 110

  • Tool radius larger than inside corner radius in program
  • Wrong tool called for the operation
  • Tool radius in tool table entered incorrectly (too large)
  • Contour programming error creating pocket smaller than tool

How to clear alarm 110

  1. Use a smaller diameter tool for the operation
  2. Verify tool radius in tool table matches physical tool
  3. Check contour geometry for minimum radius requirements
  4. Modify contour to accommodate larger tool if design permits
