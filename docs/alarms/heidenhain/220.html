Heidenhain Alarm 220 — MEMORY BACKUP BATTERY LOW

warning

The buffer battery that retains NC memory (parameters, programs, tool data) when the control is powered off is running low.

Likely causes of Heidenhain alarm 220

  • The backup battery has reached the end of its service life
  • The battery was not replaced during scheduled maintenance
  • The control was left without main power for an extended period, draining the battery faster

How to clear alarm 220

  1. Replace the backup battery as soon as possible while the control is powered on
  2. Back up all programs, parameters, and tables before replacing the battery
  3. Follow the manufacturer's procedure for battery replacement order
  4. Verify the date, time, and parameters after replacement
