Heidenhain Alarm 601 — MOTOR OVERTEMPERATURE

error

The servo motor temperature has exceeded its maximum operating temperature.

Likely causes of Heidenhain alarm 601

  • Sustained heavy cutting load
  • Motor cooling fan failure
  • Blocked motor ventilation
  • Motor bearing failure generating heat

How to clear alarm 601

  1. Stop production and allow motor to cool
  2. Check motor cooling fan operation
  3. Clear motor ventilation path
  4. Reduce cycle duty — allow more cool-down time
  5. If alarm recurs quickly, inspect motor bearings and fan
