Heidenhain Alarm 202 — AXIS NOT DEFINED

warning

A motion block references an axis that is not configured on this machine.

Likely causes of Heidenhain alarm 202

  • Program written for a 5-axis machine but running on 3-axis
  • Axis name typo (e.g., U, V, W axes not configured)
  • Wrong post-processor used for this machine configuration

How to clear alarm 202

  1. Check that all axes in the program match the machine configuration
  2. Verify post-processor is set correctly for this specific machine
  3. Remove or modify blocks that reference non-existent axes
