Heidenhain Alarm 159 — CHANGE TOOL

warning

The tool life management system indicates the active tool should be changed. The tool has reached or exceeded its programmed life.

Likely causes of Heidenhain alarm 159

  • Tool life time or piece count exceeded
  • Tool wear monitoring triggered a change request
  • TOOL LIFE management activated for this tool

How to clear alarm 159

  1. Change the tool at the next suitable point in the program
  2. Update tool data with new tool geometry if inserting different tool
  3. Reset tool life counter after tool change
  4. Inspect the tool — verify it is indeed worn
