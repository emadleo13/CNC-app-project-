Heidenhain Alarm 50 — ERROR IN POCKET TABLE

error

A tool pocket assignment conflict was detected in the tool magazine pocket table. The pocket data is inconsistent.

Likely causes of Heidenhain alarm 50

  • Two tools assigned to the same pocket
  • Pocket table data corrupted
  • Manual tool change not registered in pocket table
  • Tool magazine synchronization lost after power failure during tool change

How to clear alarm 50

  1. Open the pocket table and check for duplicate pocket assignments
  2. Verify each pocket has only one tool assigned
  3. Synchronize pocket table with physical magazine state
  4. Re-enter pocket assignments if data is corrupted
  5. Check magazine sensors if synchronization keeps failing
