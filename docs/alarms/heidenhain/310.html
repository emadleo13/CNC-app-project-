Heidenhain Alarm 310 — SPINDLE SPEED MISSING

warning

A spindle speed has not been programmed for a cutting move. The control requires an active spindle speed before machining.

Likely causes of Heidenhain alarm 310

  • S value not programmed before cutting moves
  • TOOL CALL without spindle speed specification
  • Spindle speed cancelled and not reprogrammed
  • Program restart skipped block containing S value

How to clear alarm 310

  1. Add spindle speed to TOOL CALL: TOOL CALL 1 Z S5000
  2. Program M3/M4 with S value before cutting moves
  3. Verify spindle speed is defined for the active tool
  4. Check if S value was in a block that was skipped during restart
