Heidenhain Alarm 1000 — MACHINE DATA BACKUP NEEDED

warning

The machine configuration has changed since the last backup. A new backup of machine data is recommended to protect against data loss.

Likely causes of Heidenhain alarm 1000

  • Machine parameters were modified
  • Tool table or fixture table data changed significantly
  • PLC program was updated
  • Firmware update was performed
  • Compensation tables were recalibrated

How to clear alarm 1000

  1. Perform a complete machine data backup to USB or network
  2. Include tool tables, fixture tables, and machine parameters in backup
  3. Label the backup with date and description of changes
  4. Store backup in a secure location off-machine
  5. This is informational — machine will continue to operate
