Heidenhain Alarm 140 — RADIUS COMPENSATION: INCORRECT SIGN

error

The tool radius compensation direction (RR/RL) conflicts with the contour direction, risking an undercut or collision.

Likely causes of Heidenhain alarm 140

  • RR was used where RL is required, or vice versa
  • Contour direction was reversed without updating the compensation
  • Compensation was called on a contour element too small for the tool radius
  • A sub-program was mirrored without adjusting the compensation side

How to clear alarm 140

  1. Review the contour direction and switch RL/RR accordingly
  2. Run the program in graphic test mode before machining
  3. Remove compensation on arcs smaller than the tool radius
  4. Re-check mirrored sub-programs for the correct compensation side
