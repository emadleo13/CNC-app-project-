Heidenhain Alarm 100 — TOOL NOT DEFINED

error

The requested tool number is not defined in the tool table. The control cannot find tool data for the called tool.

Likely causes of Heidenhain alarm 100

  • Tool number not entered in the tool table
  • Typo in TOOL CALL block — wrong tool number
  • Tool was deleted from the tool table
  • Tool table was reset or replaced

How to clear alarm 100

  1. Create the tool entry in the tool table with correct geometry data
  2. Verify the tool number in the TOOL CALL block matches a tool table entry
  3. Check for typos in the tool number
  4. If tool table was reset, re-enter all tool data
