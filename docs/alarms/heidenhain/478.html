Heidenhain Alarm 478 — NO FEED RATE DEFINED

warning

A positioning or interpolation block is missing a feed rate (F value), and no modal feed rate is active.

Likely causes of Heidenhain alarm 478

  • F word omitted from the first positioning block
  • Previous F value was cancelled
  • Feed rate not programmed before cutting moves

How to clear alarm 478

  1. Add F value to the motion block: L X+100 Y+50 R0 FMAX or L X+100 Y+50 F500
  2. In Heidenhain format, FMAX uses rapid traverse; F_ sets cutting feed
  3. Ensure feed rate is defined before the first cutting move in each program
