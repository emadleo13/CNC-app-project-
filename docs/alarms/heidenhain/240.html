Heidenhain Alarm 240 — DATUM TABLE NOT ACTIVE

error

A datum number was called, but no datum table is active or assigned to the program.

Likely causes of Heidenhain alarm 240

  • No datum table has been selected for the program
  • The datum table file was deleted or moved
  • The called datum number exceeds the entries in the table
  • The datum table was not assigned with SEL TABLE

How to clear alarm 240

  1. Select the correct datum table with SEL TABLE
  2. Verify the datum table file exists and contains the called datum number
  3. Re-link the datum table to the program
  4. Add the missing datum number with the correct values
