Heidenhain Alarm 340 — RADIUS COMPENSATION ERROR

warning

A contour violation occurred during tool radius compensation (RL/RR). The compensated path creates an invalid geometry.

Likely causes of Heidenhain alarm 340

  • Tool radius larger than programmed contour allows
  • Sharp inside corner requiring smaller tool
  • Compensation direction (RL/RR) incorrect for contour
  • Contour elements too short for the tool radius
  • Overlapping compensation paths

How to clear alarm 340

  1. Use a smaller diameter tool
  2. Increase inside corner radii in the part design if possible
  3. Verify RL (left) or RR (right) matches the intended side of the contour
  4. Ensure contour elements are longer than the tool radius
  5. Check for very short line segments that may cause compensation issues
