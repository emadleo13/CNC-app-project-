Heidenhain Alarm 120 — INVALID TOOL AXIS

warning

The tool axis does not match the current working plane. The tool orientation is incompatible with the active plane for machining.

Likely causes of Heidenhain alarm 120

  • Tool axis (Z) conflicts with selected working plane
  • Working plane changed without updating tool axis
  • TOOL CALL with wrong axis specification
  • 5-axis operation with incorrect tilted plane setup

How to clear alarm 120

  1. Verify TOOL CALL axis matches the intended working plane
  2. Ensure working plane selection is consistent with tool axis
  3. For 3-axis: TOOL CALL with Z axis for G17 (XY) plane
  4. Cancel tilted working plane (PLANE RESET) if not needed
