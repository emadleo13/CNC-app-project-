Heidenhain Alarm 150 — DEPTH VALUE MISSING IN CYCLE

error

A drilling or milling cycle was called without a required depth parameter.

Likely causes of Heidenhain alarm 150

  • A required Q-parameter was left blank in the cycle definition
  • The cycle definition is incomplete
  • The wrong cycle number was called for the operation
  • A Q-parameter was accidentally deleted while editing

How to clear alarm 150

  1. Open the cycle definition and enter the missing depth value
  2. Verify all Q-parameters required by the cycle are filled in
  3. Check the cycle overview in the manual for the required parameters
  4. Re-define the cycle from the cycle menu
