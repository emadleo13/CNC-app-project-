Heidenhain Alarm 390 — TOOL MEASUREMENT SYSTEM FAULT

warning

The tool measurement touch trigger probe (table-top tool setter) has a fault or is not responding.

Likely causes of Heidenhain alarm 390

  • Tool setter not calibrated or calibration expired
  • Coolant on tool setter optical receiver
  • Tool setter cable disconnected
  • Tool setter battery low (wireless type)
  • Tool setter signal cable damaged

How to clear alarm 390

  1. Clean the tool setter tip and optical window
  2. Calibrate the tool setter (Cycle 460)
  3. Check tool setter cable connection
  4. Replace battery if wireless tool setter
  5. Check tool setter signal in PLC diagnostics
