Heidenhain Alarm 182 — FEED RATE HIGHER THAN ALLOWED

warning

The commanded feed rate exceeds the maximum allowed value for the current gear stage or axis.

Likely causes of Heidenhain alarm 182

  • F value too high in program
  • Wrong gear stage active for commanded speed
  • Machine parameter for maximum feed not set correctly

How to clear alarm 182

  1. Reduce the F value in the NC program
  2. Select the correct spindle gear range
  3. Verify the axis feed rate limit in machine parameters
