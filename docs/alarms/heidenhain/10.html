Heidenhain Alarm 10 — AXIS LIMIT SWITCH ACTIVATED

error

One or more axes have triggered a hardware or software travel limit switch. All axis motion is stopped.

Likely causes of Heidenhain alarm 10

  • Programmed move exceeds the machine travel limits
  • Axis was jogged past a limit switch in manual mode
  • Software limit switch values are set incorrectly
  • Reference run was not completed before the limit was checked

How to clear alarm 10

  1. In manual mode, jog the axis away from the limit switch in the opposite direction
  2. Check the program for moves that exceed the machine's travel range
  3. Verify the software limit switch values in the machine parameters
  4. Perform a reference (homing) run if the axis position is unknown
