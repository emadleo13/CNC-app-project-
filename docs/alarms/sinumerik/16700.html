Siemens Sinumerik Alarm 16700 — Tool not found in tool management

error

The tool number called (T word) is not defined in the tool management system.

Likely causes of Siemens Sinumerik alarm 16700

  • Tool not created in tool management
  • Wrong T number in program
  • Tool was deleted from tool management

How to clear alarm 16700

  1. Create the tool in the tool management with correct number and type
  2. Verify T number in program matches the tool management database
  3. Check if tool was accidentally deleted and re-enter geometry data
