Siemens Sinumerik Alarm 14100 — Drive fault

critical

A servo drive has reported a hardware or internal fault. Check the 380xxx alarm series for more details.

Likely causes of Siemens Sinumerik alarm 14100

  • Drive hardware fault
  • Power module fault
  • Communication error between NCK and drive
  • Drive firmware error

How to clear alarm 14100

  1. Check 380xxx alarm number for specific drive fault
  2. Read drive diagnostics via the machine start-up screen
  3. Power cycle the machine completely
  4. Check DRIVE-CLiQ cable connections if applicable
  5. Contact Siemens service if drive hardware is faulty
