Siemens Sinumerik Alarm 21611 — Axis cannot be referenced (homed)

error

The homing sequence for the axis could not be completed successfully.

Likely causes of Siemens Sinumerik alarm 21611

  • Reference switch not found or signal missing
  • Encoder zero mark not found
  • Axis at or past the reference switch already
  • Drive fault preventing movement

How to clear alarm 21611

  1. Check reference switch wiring and signal in PLC diagnostics
  2. Jog axis away from reference position and retry
  3. Verify encoder cable and connector
  4. Check machine data for reference point parameters (MD34000-MD34100)
