Siemens Sinumerik Alarm 10601 — DRIVE ENABLE MISSING

error

The drive enable signal is not present. The drive cannot energize the motor without this signal.

Likely causes of Siemens Sinumerik alarm 10601

  • PLC not sending drive enable (DB21 enable bits)
  • Safety chain open preventing drive enable
  • Drive internal fault blocking enable acceptance
  • Hardware enable input not wired correctly
  • Previous alarm blocking drive enable

How to clear alarm 10601

  1. Check PLC diagnostics for drive enable bit status (DB21)
  2. Verify safety chain is satisfied (E-Stop released, doors closed)
  3. Clear any active drive alarms that may block enable
  4. Check hardware enable wiring at drive terminal
  5. Power cycle if enable was lost due to transient fault
