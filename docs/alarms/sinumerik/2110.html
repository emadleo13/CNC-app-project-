Siemens Sinumerik Alarm 2110 — SPEED SETPOINT LIMITED

warning

The velocity limitation is active for an axis. The commanded velocity has been clamped to the maximum allowed value.

Likely causes of Siemens Sinumerik alarm 2110

  • Programmed feed rate exceeds axis maximum velocity
  • Jerk limitation active reducing achievable speed
  • Machine data MD32000 (max axis velocity) set too low
  • Axis approaching travel limit causing speed reduction

How to clear alarm 2110

  1. Reduce programmed feed rate to within axis capabilities
  2. Check machine data MD32000 for maximum velocity setting
  3. Verify acceleration and jerk parameters allow reaching commanded speed
  4. This may be informational — axis will still move but at reduced speed
