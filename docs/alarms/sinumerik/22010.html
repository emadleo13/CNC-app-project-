Siemens Sinumerik Alarm 22010 — Axis must be homed (referenced) first

warning

An operation requiring a homed axis was requested but the axis has not completed its reference point approach.

Likely causes of Siemens Sinumerik alarm 22010

  • Machine was just powered on and axes not homed
  • Reference run was interrupted
  • An alarm cleared the homed status

How to clear alarm 22010

  1. Perform reference point approach: activate REF mode and press axis + key
  2. Home all axes in correct sequence as specified by machine builder
  3. Check for alarms that may have reset the homed status
