Siemens Sinumerik Alarm 1004 — Axis cannot be moved

warning

The axis is in a state where movement is not permitted. Drive enable is missing or axis has a blocking condition.

Likely causes of Siemens Sinumerik alarm 1004

  • Drive enable signal from PLC not set
  • Axis inhibit active in PLC
  • Safety relay not energized
  • Axis in fault state

How to clear alarm 1004

  1. Check DB21 drive enable bits in PLC diagnostics
  2. Verify safety relay and E-Stop chain are satisfied
  3. Clear active alarms and check axis enable logic
  4. Check PLC ladder for conditions inhibiting axis movement
