Siemens Sinumerik Alarm 14010 — Feedrate = 0

warning

A feed-dependent motion command was executed but the active feedrate is zero.

Likely causes of Siemens Sinumerik alarm 14010

  • F word missing from the program block
  • F0 programmed (zero feedrate)
  • Feed override dial turned to 0%
  • G63 (tapping mode) active without correct feedrate

How to clear alarm 14010

  1. Add F value to the motion block: G1 X_ Y_ F100
  2. Check feed override potentiometer is not at 0%
  3. Verify the correct feed group is active (G93/G94/G95)
