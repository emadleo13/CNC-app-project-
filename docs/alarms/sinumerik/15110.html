Siemens Sinumerik Alarm 15110 — Spindle speed exceeds maximum

warning

The programmed spindle speed exceeds the machine or gear stage maximum.

Likely causes of Siemens Sinumerik alarm 15110

  • S value too high for current gear stage
  • Wrong gear range programmed
  • Machine data for maximum speed set too low

How to clear alarm 15110

  1. Reduce the S (spindle speed) value in the program
  2. Select the correct gear range (M40/M41/M42/M43)
  3. Verify maximum speed limits in machine data MD35100
