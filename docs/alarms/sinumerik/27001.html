Siemens Sinumerik Alarm 27001 — Work offset error

warning

The active work offset (G54-G599) contains invalid or out-of-range data.

Likely causes of Siemens Sinumerik alarm 27001

  • Zero offset value not set or was cleared
  • Offset value outside machine travel range
  • Wrong offset number active in program

How to clear alarm 27001

  1. Verify work offset values in the zero offset table
  2. Measure and set the correct work zero position
  3. Check which G54-G599 offset is active in the program
