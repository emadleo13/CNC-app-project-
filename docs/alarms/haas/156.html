Haas Alarm 156 — MISSING FEEDRATE

warning

A cutting motion (G01, G02, G03) was commanded without an active feedrate (F word).

Likely causes of Haas alarm 156

  • F word missing from the program block
  • F value is zero
  • Modal feedrate was cleared without being reset

How to clear alarm 156

  1. Add an F word to the first cutting move: G01 X_ Y_ F100.
  2. Verify F value is non-zero
  3. Check that G94 (feed per minute) or G95 (feed per rev) is active as expected
