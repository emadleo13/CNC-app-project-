Haas Alarm 120 — OVER TRAVEL — NEGATIVE Z

error

The Z axis exceeded its negative software or hardware travel limit.

Likely causes of Haas alarm 120

  • Program depth exceeds machine Z travel
  • Tool length offset not active — all Z moves go too deep
  • Work offset Z incorrectly set near machine limit

How to clear alarm 120

  1. Jog Z axis up (positive direction) to clear limit
  2. Ensure G43 H_ is active before all Z cutting moves
  3. Verify Z work offset is correctly measured from part surface
  4. Check all Z depth values in program
