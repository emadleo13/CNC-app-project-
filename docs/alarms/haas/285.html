Haas Alarm 285 — LINEAR SCALE FAULT

error

An optional linear scale (glass or magnetic) feedback device has a fault or lost signal.

Likely causes of Haas alarm 285

  • Scale read head misaligned or damaged
  • Scale contaminated with coolant or chips
  • Scale cable disconnected
  • Scale hardware failure

How to clear alarm 285

  1. Clean linear scale and read head with dry air
  2. Check read head alignment — should be within specification
  3. Inspect scale cable for damage
  4. Test signal with oscilloscope if available
  5. Replace read head if signal is absent
