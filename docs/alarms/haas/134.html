Haas Alarm 134 — PROBE ALREADY TRIPPED

warning

The probe signal was already active (tripped) before the probing cycle started. The probe must be in an undeflected state before beginning a measurement.

Likely causes of Haas alarm 134

  • Probe tip already in contact with workpiece or fixture
  • Probe stylus bent causing false trigger
  • Probe signal stuck in triggered state (hardware fault)
  • Debris on probe tip holding it deflected

How to clear alarm 134

  1. Move probe away from all surfaces before starting probing cycle
  2. Inspect probe stylus for bending or damage
  3. Clean probe tip and check for debris holding stylus deflected
  4. Verify probe signal state in Diagnostics — should show NOT tripped
  5. Replace probe stylus if bent
