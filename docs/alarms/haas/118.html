Haas Alarm 118 — TOOL OFFSET NOT SET

warning

A G43 tool length compensation call references an H offset that is zero or not set.

Likely causes of Haas alarm 118

  • Tool not measured or manually entered
  • Wrong H number in G43 command
  • Offset table was cleared

How to clear alarm 118

  1. Measure the tool with the tool setter and enter length in offset table
  2. Verify the H number matches the tool offset entry number
  3. Use G43 H[tool_number] matching your tool setup
