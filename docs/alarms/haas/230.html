Haas Alarm 230 — TOOL NOT IN SPINDLE

error

The tool presence switch indicates no tool is currently held in the spindle. The machine cannot proceed with operations requiring a tool.

Likely causes of Haas alarm 230

  • Tool fell out of spindle due to low drawbar pressure
  • Drawbar spring pack weakened or broken
  • Tool presence switch malfunction
  • Tool was not fully pulled into taper during tool change
  • Coolant or chips preventing proper tool seating

How to clear alarm 230

  1. Check if tool is physically present in spindle
  2. Verify drawbar clamping force — check air pressure for drawbar release
  3. Clean spindle taper and tool holder taper
  4. Test tool presence switch signal in Diagnostics > Inputs
  5. If drawbar spring pack is weak, schedule replacement
