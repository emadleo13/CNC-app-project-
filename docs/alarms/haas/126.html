Haas Alarm 126 — SOFT LIMIT — NEGATIVE DIRECTION

warning

The programmed move would exceed the negative software travel limit.

Likely causes of Haas alarm 126

  • Program has excessive negative Z depth
  • Work offset Z value incorrect
  • Tool length offset not applied

How to clear alarm 126

  1. Check Z work offset — if set at zero instead of actual surface, all Z moves will be too deep
  2. Verify tool length offset is active (G43 H_)
  3. Reduce depth-of-cut values in program
