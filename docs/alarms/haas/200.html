Haas Alarm 200 — HOME SWITCH NOT FOUND

error

The home switch was not detected during the homing (zero return) sequence.

Likely causes of Haas alarm 200

  • Home switch hardware failure
  • Home switch wiring disconnected
  • Axis moved past the switch location
  • Parameter 1 (axis home direction) set incorrectly

How to clear alarm 200

  1. Check home switch wiring connections at both the switch and the I/O board
  2. Test home switch signal in Diagnostics > Inputs
  3. Verify Parameter 1 (zero return direction) is set correctly
  4. Manually trigger the switch with a screwdriver to test
