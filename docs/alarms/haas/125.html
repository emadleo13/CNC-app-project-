Haas Alarm 125 — SOFT LIMIT — POSITIVE DIRECTION

warning

The programmed move would exceed the positive software travel limit.

Likely causes of Haas alarm 125

  • Program coordinates exceed machine travel
  • Incorrect work offset placed near edge of travel
  • Tool length offset not applied, causing Z overtravel

How to clear alarm 125

  1. Verify work offset (G54) is correctly set — it may be too close to machine limits
  2. Check all axis coordinates in the program relative to machine travel
  3. Ensure tool length offset is loaded (G43 H_) before Z moves
  4. Review soft limit Parameters (43-48)
