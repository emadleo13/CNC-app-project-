Haas Alarm 121 — OVER TRAVEL — X AXIS

error

The X axis exceeded its software or hardware travel limit.

Likely causes of Haas alarm 121

  • Program X coordinates outside machine travel range
  • Work offset X value places origin outside usable area
  • G-code with incremental moves accumulating past limit

How to clear alarm 121

  1. Jog X axis back within travel limits
  2. Recheck work offset X position
  3. Verify all X coordinates in program are within machine travel
  4. Check for incremental (G91) moves that exceed travel
