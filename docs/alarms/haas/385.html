Haas Alarm 385 — TOOL BREAK DETECTED

error

The spindle load monitoring system or tool break sensor detected a tool failure.

Likely causes of Haas alarm 385

  • Tool broken or chipped during cutting
  • Feed rate or depth of cut too aggressive for tool
  • Wrong cutting parameters for material
  • Incorrect tool selected for operation

How to clear alarm 385

  1. Stop cycle and inspect tool in spindle
  2. Replace broken or worn tool
  3. Verify cutting parameters are appropriate for tool and material
  4. Check tool break detection sensitivity settings
