Haas Alarm 117 — HARD LIMIT — NEGATIVE DIRECTION

error

An axis reached its negative hard travel limit switch.

Likely causes of Haas alarm 117

  • Program error causing axis to travel past negative boundary
  • Incorrect work offset position
  • Limit switch malfunction

How to clear alarm 117

  1. Jog axis away from limit switch in positive direction
  2. Verify work offsets and tool length offsets are set correctly
  3. Check G-code for incorrect negative coordinate values
