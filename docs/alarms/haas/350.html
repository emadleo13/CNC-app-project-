Haas Alarm 350 — SERVO DRIVE FAULT — GENERAL

error

A servo drive has reported a general fault. Check the drive fault LED indicators for a specific code.

Likely causes of Haas alarm 350

  • Drive internal hardware fault
  • Power supply fault
  • Motor fault detected by drive
  • Drive firmware error

How to clear alarm 350

  1. Read and record the LED blink code from the servo drive
  2. Power cycle the machine completely
  3. Check incoming DC bus voltage to drives
  4. Inspect motor and cable connections
  5. Contact Haas service if drive fault recurs
