Mazak Alarm EX5001 — DOOR INTERLOCK OPEN

error

The automatic door (or splash guard door) interlock switch is open while the control is in a state that requires the door closed.

Likely causes of Mazak alarm EX5001

  • Operator opened the door during an automatic cycle
  • Door did not close fully — latch not engaged
  • Door interlock switch misaligned or wiring fault
  • Automatic door motor fault preventing full closure

How to clear alarm EX5001

  1. Close the door completely until the latch engages, then press CYCLE START
  2. Check the door interlock switch alignment and continuity
  3. Inspect the automatic door drive belt/motor for faults
  4. Do NOT defeat the door interlock — it is a critical operator safety device
