Mazak Alarm EX1102 — PROGRAM ERROR: ILLEGAL COMMAND

warning

The NC program contains a G-code, M-code, or address combination that is not valid in the current mode or is not supported by this control.

Likely causes of Mazak alarm EX1102

  • Program written for a different control dialect (e.g., generic Fanuc code run in EIA/ISO mode without conversion)
  • Typo in a G or M code number
  • An option (e.g., 5-axis, Multi-Tasking) required by the command is not installed
  • Mixed modal groups conflict in the same block

How to clear alarm EX1102

  1. Open the program editor — the control highlights the offending block
  2. Verify the G/M code is supported on this machine model and control software level
  3. Check whether the required machine option is installed (Maintenance > Option screen)
  4. Split conflicting modal commands into separate blocks
