Mazak Alarm EX9301 — PALLET CHANGE ALARM (APC)

error

The automatic pallet changer did not complete the pallet exchange sequence (applies to Pallet Changer / Multi-Pallet equipped models).

Likely causes of Mazak alarm EX9301

  • Pallet not fully seated on the locating pins
  • Pallet clamp sensor not detecting the locked condition
  • Hydraulic/pneumatic pressure insufficient for the pallet shuttle or clamps
  • Obstruction in the pallet changer travel path

How to clear alarm EX9301

  1. Check pallet seating and clamp sensor indicators on the diagnostic screen
  2. Verify hydraulic/pneumatic pressure is at the specified operating level
  3. Inspect the pallet changer mechanism for obstructions or debris
  4. Run the APC recovery sequence from the maintenance screen
  5. Do not manually move the pallet shuttle without following the recovery procedure
