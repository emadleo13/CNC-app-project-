Mazak Alarm EX9205 — TOOL EYE (TOOL SETTER) MEASUREMENT ERROR

warning

The tool length/diameter measurement cycle using the tool setting probe (Tool Eye) did not complete successfully.

Likely causes of Mazak alarm EX9205

  • Tool did not contact the tool setter within the programmed approach distance
  • Tool setter contact surface contaminated with chips or coolant
  • Tool setter signal cable damaged or loose
  • Wrong tool number or offset register selected for the measurement cycle

How to clear alarm EX9205

  1. Clean the tool setter contact surface and stylus
  2. Check the tool setter signal in the I/O diagnostic screen by manually triggering it
  3. Verify the approach distance and tool number programmed in the measurement cycle
  4. Inspect the tool setter cable and connector for damage
