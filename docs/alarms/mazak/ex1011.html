Mazak Alarm EX1011 — OVERTRAVEL: + DIRECTION

error

An axis has reached or would exceed its positive software stroke limit. Motion in the positive direction is blocked.

Likely causes of Mazak alarm EX1011

  • Program coordinates command a position beyond the positive stroke limit
  • Work coordinate offset (G54-G59) places the part outside machine travel
  • Incremental (G91) moves accumulated past the limit
  • Stroke limit parameter set incorrectly after a backup restore

How to clear alarm EX1011

  1. Press RESET, then jog the axis in the negative direction away from the limit
  2. Check the work coordinate offset values in the Common Variable / Work Offset screen
  3. Review the program block shown in the alarm message for the offending coordinate
  4. Verify stroke limit parameters (Parameter 1320/1321 series on M800/M80) match the machine specification
