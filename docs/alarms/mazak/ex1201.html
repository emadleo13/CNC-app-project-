Mazak Alarm EX1201 — AXES NOT RETURNED TO REFERENCE POINT

warning

An automatic or manual operation requiring absolute position reference was requested before the axes completed their reference (zero) return.

Likely causes of Mazak alarm EX1201

  • Control was powered on and reference return was not performed
  • Reference return was interrupted by an alarm or E-STOP
  • Absolute position detector battery failure caused loss of reference (incremental scale machines)

How to clear alarm EX1201

  1. Select reference return mode and press the axis start for each axis (or ALL AXIS)
  2. Clear any active alarms before attempting reference return
  3. If using absolute encoders, verify encoder battery voltage before re-referencing
  4. After completing reference return, the alarm clears automatically
