Mazak Alarm M01 BATTERY — ABSOLUTE POSITION BATTERY LOW

warning

The backup battery for the absolute position detection system (servo/spindle encoders) is low and needs replacement.

Likely causes of Mazak alarm M01 BATTERY

  • Battery has reached its normal end of life (typically 2-3 years)
  • Control was left powered off for an extended period, draining the battery faster

How to clear alarm M01 BATTERY

  1. Replace the absolute encoder backup battery as soon as possible without powering off the control
  2. Use the battery type specified in the Mazak maintenance manual
  3. After replacement, verify all axis absolute positions are still correct
  4. If the battery dies completely before replacement, all axes must be re-referenced
