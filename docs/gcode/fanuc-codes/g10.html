G10 — Programmable Offset Input

Fanuc Code · Fanuc

Set work offsets (L2) or tool offsets (L11/L10) from within the program.

Syntax

G10 L2 P1 X_ Y_ Z_  (set G54)
G10 L11 P_ R_  (tool wear)

Watch out

Permanently changes offset tables. Verify before running.
