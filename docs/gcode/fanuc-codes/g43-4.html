G43.4 — Tool Centre Point Control

Fanuc Code · Fanuc

Tool Centre Point (TCP) control mode. Maintains tool tip position during tilted-plane moves.

Syntax

G43.4 H_

Watch out

Requires 5-axis option. Cancel with G49.
