M198 — Subprogram Call from External Device

Mazak Code · Mazak

Calls a subprogram stored on an external device (memory card, USB, or network share) rather than from internal program memory, useful for very large programs run in DNC-style operation.

Syntax

M198 P_ (program number)

Watch out

The external device/path must be configured and connected before the calling program runs.
