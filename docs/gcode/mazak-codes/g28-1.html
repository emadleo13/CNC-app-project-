G28.1 — Second Reference Point Return (Turret/B-axis Index)

Mazak Code · Mazak

Sends the specified axis (commonly the turret or B-axis on Multi-Tasking machines) to a second, user-defined reference position used for tool-change clearance.

Syntax

G28.1 B_ (or relevant axis)

Watch out

Ensure the path to the second reference point is clear of fixtures and the opposing spindle/turret.
