G68 — Coordinate System Rotation

Mazak Code · Mazak

Rotates the programmed coordinate system about a specified center point by a given angle, allowing a feature programmed once to be repeated at multiple angular positions.

Syntax

G68 X_ Y_ R_ (center X/Y, rotation angle R)  ... G69 (cancel)

Watch out

All subsequent coordinates are interpreted in the rotated system until G69 cancels it.
