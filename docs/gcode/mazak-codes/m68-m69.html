M68 / M69 — Hydraulic Chuck Clamp / Unclamp

Mazak Code · Mazak

M68 clamps the hydraulic chuck (or secondary chuck on a sub-spindle) to grip the workpiece; M69 releases it.

Syntax

M68  (clamp)   M69  (unclamp)

Watch out

Never command M69 with the spindle rotating or while a part is unsupported — workpiece can eject.
