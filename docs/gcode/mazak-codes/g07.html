G07 — Hypothetical Axis Interpolation

Mazak Code · Mazak

Designates an axis as a 'hypothetical' (dummy) axis for interpolation purposes — used on Multi-Tasking machines so a rotary or auxiliary axis can be treated as a linear axis in a interpolation block.

Syntax

G07 a1 (a = axis address, 1 = enable hypothetical mode)

Watch out

Mitsubishi/Mazak-specific. Cancel with G07 a0 before normal moves on that axis.
