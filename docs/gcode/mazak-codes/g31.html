G31 — Skip Function

Mazak Code · Mazak

Linear feed move that is aborted immediately if the skip signal (e.g. a probe or limit switch) is received, with the position at the moment of the signal captured into a system variable.

Syntax

G31 X_ Y_ Z_ F_

Watch out

Following moves should reference the captured skip position before assuming probe contact occurred.
