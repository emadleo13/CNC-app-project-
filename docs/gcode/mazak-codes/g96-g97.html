G96 / G97 — Constant Surface Speed Control ON/OFF

Mazak Code · Mazak

G96 maintains a constant cutting surface speed (m/min or sfm) by automatically adjusting spindle RPM as the turning diameter changes; G97 returns to direct RPM control.

Syntax

G96 S_ (surface speed)  /  G97 S_ (RPM)

Watch out

Set a maximum spindle speed with G50/G92 before using G96 to prevent over-speed at small diameters.
