G68.2 — Tilted Working Plane Command

Mazak Code · Mazak

Establishes a tilted work coordinate system on a 5-axis or Multi-Tasking machine, defined by Euler angles, so that subsequent G01/G02/G03 moves and cycles are programmed in the tilted plane.

Syntax

G68.2 X_ Y_ Z_ I_ J_ K_  (origin + tilt angles)  followed by G53.1 to align rotary axes

Watch out

Requires the 5-axis option. Always cancel with G69 before returning to the machine coordinate system.
