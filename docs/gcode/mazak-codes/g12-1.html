G12.1 — Polar Coordinate Interpolation ON

Mazak Code · Mazak

Converts commanded X/C (or X/Y) motion into synchronized linear and rotary axis motion, allowing flat features (slots, flats) to be milled on a turning center using straight-line G01/G02/G03 blocks.

Syntax

G12.1 ... G01/G02/G03 X_ C_ F_ ... G13.1

Watch out

Requires C-axis and live tooling. Always pair with G13.1 to cancel.
