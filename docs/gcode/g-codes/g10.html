G10 — Programmable Data Input

G-Code · Haas, Generic

Allows work offsets and tool offsets to be set from within the program.

Syntax

G10 L2 P1 X_ Y_ Z_ (set G54)  |  G10 L1 P_ R_ Z_ (set tool offset)

Watch out

G10 permanently modifies offset tables. Double-check values before running.
