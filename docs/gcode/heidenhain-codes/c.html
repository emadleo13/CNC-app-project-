C — Circular Traverse (Center)

Heidenhain Code · Heidenhain

Arc move using a previously defined circle center (CC). Direction set by DR+ (CCW) or DR- (CW).

Syntax

C X+_ Y+_ DR+  F_  (CCW arc to X,Y)

Watch out

Must define CC before using C.
