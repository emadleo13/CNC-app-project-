FN0 — Variable Assignment (FN 0)

Heidenhain Code · Heidenhain

Assign a numeric value to a Q parameter (variable). Q parameters enable parametric programming.

Syntax

FN 0: Q_ = _  (e.g. FN 0: Q1 = 25.0)
