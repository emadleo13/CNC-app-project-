CYCL CALL — Cycle Call

Heidenhain Code · Heidenhain

Execute the last defined cycle at the current tool position. Positioning move must precede.

Syntax

CYCL CALL  or  CYCL CALL PAT  (on a point pattern)

Watch out

Cycle must be defined before CYCL CALL.
