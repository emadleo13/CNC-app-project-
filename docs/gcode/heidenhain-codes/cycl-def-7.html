CYCL DEF 7 — Datum Shift (Cycle 7)

Heidenhain Code · Heidenhain

Shift the active datum (workpiece zero) to a new position. Used to machine multiple identical features.

Syntax

CYCL DEF 7.0 DATUM SHIFT
  7.1 X+_
  7.2 Y+_
  7.3 Z+_

Watch out

Cancel with Cycle 7 at X+0 Y+0 Z+0.
