CYCL DEF 8 — Mirror Image (Cycle 8)

Heidenhain Code · Heidenhain

Mirror the programmed geometry across a specified axis or axes.

Syntax

CYCL DEF 8.0 MIRROR IMAGE
  8.1 X (to mirror about X)

Watch out

Cancel by calling Cycle 8 without axis specification.
