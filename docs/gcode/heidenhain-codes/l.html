L — Linear Traverse

Heidenhain Code · Heidenhain

Move tool in a straight line to the programmed position. Equivalent to G01 in ISO.

Syntax

L X+_ Y+_ Z+_ F_  RR/RL/R0  (RR=radius right, RL=radius left, R0=no compensation)
