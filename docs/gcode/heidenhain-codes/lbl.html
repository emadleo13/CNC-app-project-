LBL — Label (Subprogram Start/End)

Heidenhain Code · Heidenhain

Marks start of a subprogram or repeat section. LBL 0 marks the end.

Syntax

LBL _  (start)
LBL 0  (end)

Watch out

LBL 0 terminates the subprogram and returns control.
