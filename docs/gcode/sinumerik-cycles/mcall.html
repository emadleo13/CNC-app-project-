MCALL — Modal Cycle Call

Sinumerik Cycle

Activates a cycle modally so it executes at every subsequent position block.

Syntax

MCALL CYCLE81(...)  ; then list positions
MCALL  ; to deactivate

Watch out

Always deactivate with MCALL (no arguments) when done.
